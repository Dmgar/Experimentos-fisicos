# Experimentos-físicos

##  Descripción
Repositorio con experimentos de física, incluyendo:
- Simulaciones numéricas
- Análisis de datos experimentales
- Procesamiento de video e imágenes para física

##  Estructura
- `pendulo_simple/`: Análisis de movimiento pendular
- `trayectoria_proyectiles/`: Simulación y ajuste de trayectorias
- `procesamiento_imagenes/`: Extracción de datos desde videos

##  Cómo usar
1. Clonar repositorio
2. Instalar dependencias: `pip install -r requirements.txt`
3. Explorar notebooks en cada carpeta

##  Experimentos incluidos
| Experimento | Descripción | Tecnologías |
|------------|-------------|-------------|
| Péndulo simple | Análisis de periodo y ajuste | Python, NumPy, SciPy |
| ... | ... | ... |

##  Tecnologías
- Python 3.9+
- Jupyter Notebook
- OpenCV, NumPy, Matplotlib, SciPy
